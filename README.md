# 拾物

把手机变成一台复古扫描仪：对着想留下的东西拍一圈，等一会儿，它就在手机里变成可以转着看、可以导出的 3D 模型。

没有建模软件，没有扫描仪，也不用会画画——会摁快门就行。

## 能做什么

- **把实物变成 3D 模型**：手办、杯子、鞋子、摆件、瓶罐、工具、模型零件……能拍全的东西大多能重建。
- **模型留在手机里**：扫描结果存在本机，随时翻出来转着看。
- **带走它**：双击放大看细节，一键分享给朋友（GLB 文件），或保存到「下载」文件夹，拿去建模软件、网页、游戏引擎里继续用。
- **可以连着拍**：提交后取景器立刻复位，不用等上一个模型出结果，就能接着拍下一件。

## 装到手机上

- 系统要求：**Android 8.0 及以上**，**64 位 ARM 机型**（绝大多数 2018 年后的手机都满足）。
- 安装 `Shiwu.apk`，首次打开请允许**相机**权限（拍底片用）；从相册导入底片时会再要一次**相册**权限。

## 第一次用

打开后会弹一份五页的操作手册，读完就懂。核心就四步：

1. **对准**——把要拍的东西放在取景屏中间。画面里只有一个物体时，它会自动被四角框住；点屏幕上别的东西，可以改选目标。
2. **拍一圈**——短按旋钮拍一帧，指针每次转 45°。绕物体走一圈，**8–12 帧**最理想，光线均匀、表面有纹理，出来的模型更完整。
3. **长按提交**——长按旋钮开始成像。画面会闪一下，任务折进「资产」按钮，取景器立刻可以接着拍。
4. **在资产里等结果**——进度、失败重试、成品预览都在资产页。底片会一直留着，直到模型真的下载到本地。

> 每台"机身"最多存 12 帧底片。单帧也能提交（就是单图模式），但多拍几帧的模型完整得多。

## 机身说明

| 部件 | 怎么用 |
|---|---|
| **旋钮 / 快门** | 短按拍一帧，长按提交。外面那圈琥珀色进度环就是已拍帧数。 |
| **灯 / LIGHT** | 开关手电筒，暗处拍底片用。 |
| **配置 / CONFIG** | 切到参数页：引擎、精度、区域、演示模式、链路测试、导入底片、操作手册。再按一次返回取景。 |
| **资产 / ARCHIVE** | 切到资产仓库：正在处理、失败可重试、已完成的模型都在这里，点一下进入 3D 预览。 |
| **子显示屏** | 顶部那条窄屏：已拍帧数、进度、当前引擎与精度、操作提示。 |

## 让重建成功率高一点

- **光要匀**：自然光或室内均匀照明最好，避免一边强光一边全黑、避免打闪光灯。
- **背景干净**：物体后面最好没有和它颜色接近的东西。
- **转着拍**：围着物体走，视角变化大一些，别只在一个角度小幅度挪动。
- **别拍这些**：透明玻璃、镜面金属、纯色无纹理的平面、会动的物体（宠物、风扇）——这些本来就不容易重建。
- **贴着拍**：让物体占画面大部分，但别出画面。

## 关于密钥

重建用的是**群核 Aholo Lux3D**，需要一个 API Key：

- 配置页最底下有「**服务舱 / SERVICE BAY**」，可以**在应用内**一站式走完：打开 Lux3D 控制台 → 登录并复制密钥 → 回到应用自动读取剪贴板 → 校验通过后写入本机。
- 密钥**只保存在你的手机上**，不会上传到任何地方；界面里默认以圆点掩码显示，需要时点「显示」。
- **没有密钥也能试**：打开「演示模式」，全流程照常走完，只是结果换成内置的示例模型。
- 生成会占用**你自己账号的额度**：极速引擎（G1-Turbo）约 1 分钟，精细引擎（G1）约 5 分钟，额度与并发以 Lux3D 控制台为准。

## 常见问题

**拍失败了怎么办？**
底片会保留。资产页里那条失败记录可以直接「重试」，不用重拍。

**模型糊、有破洞、缺一块？**
多拍几帧（尤其物体背面和底部）、换到光线均匀的地方，或把精度调到「精细」再重试。

**帧数满了？**
上限 12 帧。拍完就提交，或先在配置页「清空底片」重来。

**手边没网 / 不想花额度？**
配置页「演示模式」可以完整走一遍流程；也可以把引擎切到「本地」，用机内重建（效果不如云端，但完全离线、不耗额度）。

**能直接用在别的软件里吗？**
可以。成品是标准 GLB，分享或保存到「下载」后，Blender、网页 `<model-viewer>`、游戏引擎都能直接打开。

## 你的数据

- 底片照片只在**提交时**上传到群核 Aholo 用于重建；不提交就一直在本机。
- 生成好的模型保存在应用私有目录，只有你导出或分享时才会离开手机。
- API Key 只存在本机设置里，不随日志外传。

## 已知限制

- 只提供 **64 位 ARM** 版本，老机型与模拟器装不上。
- 取景时相机常驻，切到面板也仍在运行（为了返回时能立刻拍），耗电会略高。
- 深色物体紧贴线缆、支架时，自动框选可能把它们连成一片，框会偏大——换个背景或点一下物体主体位置就好。
- 同一个账号的并发任务有上限（免费额度是 5 个），排队时会给出中文提示。

## 从源码构建

```bash
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

API Key 写在 `local.properties` 的 `aholo.api.key=`（该文件已在 `.gitignore` 中，不会进仓库），构建时注入为默认值；也可以在应用内「服务舱」里改。

> 工程路径含中文时依赖 `gradle.properties` 里的 `android.overridePathCheck=true`（已加）。
>
> 想用 x86 模拟器调界面，加 `-PwithX86 -PnoSubject` 出一个跳过主体分割的调试包；正式包仍是纯 arm64。
